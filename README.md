# 一口一口瘦

**把「计划吃什么—实际吃了什么—回看记录」整理成清楚的一餐。**

饮食计划、摄入记录与食谱管理微信小程序。支持按整道菜操作、编辑自己的食谱与照片，以及本地备份恢复。

**第二版已于 2026 年 10 月 14 日通过微信审核并上线。**

**uni-app · Vue 3 · TypeScript · Pinia · Vite · 本地存储**

[作品集展示](https://lsc-261013.github.io/lv-shuaichao-portfolio/) · [界面截图](#界面截图) · [本地运行](#本地运行) · [历史迭代记录](README-history-2026-10-05.md)

## 核心功能

| 场景 | 已实现的操作 |
| --- | --- |
| **安排一餐** | 计划按整道菜分组，配料按需展开；支持多选、全选、批量确认已吃、撤回与移除 |
| **记录实际摄入** | 待吃与已吃分开统计；已吃按菜份展示，支持逐食材改量、合计变化预览、撤销、历史查看与补记 |
| **维护自己的食谱** | 编辑名称、配料、克数、餐次与照片；分类查看、隐藏与恢复，批量删除内置或自建食谱 |
| **调整食材与分量** | 替换食材前预览热量变化，确认后保存；支持自定义食材、千卡 / 千焦换算，营养信息可选填 |
| **保留与迁移记录** | 编辑或删除源食谱后保留既有计划与摄入记录；支持 JSON 备份、导入预览、合并或完整恢复、导入前副本与文本出口 |

## 几个重点交互

- **计划不提前算成已吃。** 确认食用后才进入实际摄入，撤回与移除分别对应不同操作；移除计划不会删除已吃记录。
- **一道菜保持完整。** 计划与已吃按菜份组织，底层保留逐食材记录与计算，既能看整餐，也能精确修改分量。
- **改食谱不改过去。** 食谱编辑与删除保留历史计划、摄入的名称及数值；历史配图可能随源照片清理而回到默认图。
- **缺失信息清楚呈现。** 未填写身体资料也能记录；没有目标时不虚构完成百分比，未知营养显示“未完善”。

## 本地运行

安装依赖并启动 H5：

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

默认访问 `http://127.0.0.1:5173`，实际端口以终端输出为准。历史记录的验证环境为 Node.js 24.15.0 / npm 11.12.1。

类型检查、测试与构建：

```bash
npm run typecheck
npm test
npm run build
npm run build:mp-weixin
```

微信开发者工具导入 `dist/build/mp-weixin` 并使用自己的 AppID。源码 `src/manifest.json` 中 AppID 为空，编译产物需在本地生成。

H5 数据按浏览器与来源隔离，切换端口或设备后不会自动出现原记录；迁移前请先导出备份。
