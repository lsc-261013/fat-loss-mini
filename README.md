# 女性减脂助手

微信小程序 — 帮助女性用户计算减脂热量目标、记录每日饮食、根据营养素缺口推荐食谱。

## 导入微信开发者工具

1. 打开**微信开发者工具**
2. 选择**导入项目**
3. 目录选择 `dist/build/mp-weixin`
4. AppID 使用测试号或你的 AppID
5. 点击确定即可预览

## 本地开发

```bash
npm install --registry https://registry.npmmirror.com
npm run build:mp-weixin
```

构建后在微信开发者工具中打开 `dist/build/mp-weixin`。

## 页面

| 页面 | 功能 |
|------|------|
| 个人资料 | 身高/体重/年龄输入、活动系数、月经周期、BMR/减脂热量/三大营养素自动计算 |
| 饮食记录 | 45 种食材选择、克数输入、今日列表、热量进度条、营养素追踪 |
| 推荐食谱 | 根据剩余热量和营养素缺口智能推荐 7 个减脂餐组合 |

## 技术栈

- uni-app (Vue 3 + Vite)
- Pinia 状态管理
- 本地缓存持久化
- 无后端依赖
